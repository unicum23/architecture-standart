### FURPS+ Требования


| Код | Требования                                                                                                                                                                                                                                                                       | Комментарий                                           |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| F-01   | Пользователь сайта может оформить заявку на вклад, указав свои данные                                                                                                                                                           | Номер телефона и ФИО                            |
| F-02   | В интернет-банке доступен выбор вклада и отправка заявки                                                                                                                                                                                   | Клиент указывает счёт и сумму           |
| F-03   | Заявки автоматически попадают в систему обработки кол-центра                                                                                                                                                                          | Без участия клиента после отправки |
| F-04   | После рассмотрения заявки, клиент получает СМС с предложением условий                                                                                                                                                          | Отправка через текущую СМС-систему |
| F-05   | Вся информация передаётся в зашифрованном виде                                                                                                                                                                                                    |                                                                  |
| F-06   | Подтверждение условий и идентификация происходят в отделении                                                                                                                                                                         |                                                                  |
| F-07   | У сотрудников бэк-офиса есть интерфейс для подтверждения условий вклада                                                                                                                                                      |                                                                  |
| F-08   | Сайт должен поддерживать адаптивную верстку под мобильные устройства                                                                                                                                                          |                                                                  |
| U-01   | Интерфейсы должны соответствовать брендингу и стилю цифровых сервисов банка                                                                                                                                             |                                                                  |
| U-02   | Навигация по экрану и подача заявки должны быть интуитивны                                                                                                                                                                               | Для всех возрастных групп                  |
| U-03   | Персональные предложения по ставке отображаются в отдельной секции                                                                                                                                                              |                                                                  |
| R-01   | Основные сервисы ИБ и сайта для пользователя должны работать бесперебойно и быть доступны круглосуточно                                                                                          | 99.9% SLA                                                        |
| R-02   | При сбое основного ЦОДа должна быть возможность ручного или автоматического переключения                                                                                                                     |                                                                  |
| R-03   | Прямая интеграция с АБС исключается                                                                                                                                                                                                                         |                                                                  |
| P-01   | Среднее время ответа на действия клиента — не более 500 мс                                                                                                                                                                                    |                                                                  |
| P-02   | Загрузка справочников и ставок не должна вызывать задержки                                                                                                                                                                              |                                                                  |
| S-01   | Все модули должны разрабатываться с учётом популярных технологий на рынке для легкого найма людей в команду                                                                                    | Java, Spring, ReactJS, PostgreSQL                               |
| S-02   | Полностью исключить хранение данных в Excel как первоисточник и основное "хранилище"  данных                                                                                                                      |                                                                  |
| S-03   | Документация ключевых интерфейсов и процессов                                                                                                                                                                                                     | На будущее расширение                         |
| R-01   | АБС работает медленно и нет возможности для оптимизаций                                                                                                                                                                                    |                                                                  |
| R-02   | АБС не масштабируется горизонтально                                                                                                                                                                                                                        |                                                                  |
| R-03   | Новые сервисы взаимодействующие с старыми системами должны работать через прокси сервисы чтобы в будущем было проще переключать трафик на новые системы |                                                                  |
